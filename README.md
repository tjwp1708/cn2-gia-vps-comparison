## 先搞清楚：CN2 GIA 和普通 CN2 差在哪

很多人把"CN2"当成一个统一概念，其实中国电信的 CN2 至少分两档：

- **CN2 GT（Global Transit）**：早期用来缓解 163 网络拥堵的线路，2019 年以后高峰期丢包也明显，性价比一般。
- **CN2 GIA（Global Internet Access）**：电信目前最高端的回程线路，全程走 59.43 节点，稳定性最好，但带宽贵、容量有限——按官方说法，CN2 GIA 的 IP transit 成本最高可达 $120/Mbps，1Gbps 满载一个月账单能到六位数。

所以你看到市面上真正"高带宽"的 CN2 GIA VPS 不多，因为带宽成本摆在那。搬瓦工在洛杉矶两个机房部署了 8 条 10Gbps 的 CN2 GIA/CTGNet 链路，这是它能做出 2.5Gbps–10Gbps 带宽套餐的底层原因。
